# SculptCut

Документация — на русском, идентификаторы и CLI — на английском.
Перед изменениями прочитайте README.md и соответствующие исходники/тесты.

- Это локальный редактор существующих записей, без рекордера и облачного анализа.
- Не изменяйте исходные видео. Экспортируйте из оригиналов, preview допускает proxy.
- Анализ и планировщик не должны зависеть от PySide6.
- Используйте pathlib, типы, subprocess со списком аргументов и без shell=True.
- Не загружайте целое видео в RAM; долгие задачи должны поддерживать отмену.
- Время источников хранится целыми микросекундами, FPS — рациональной величиной.
- Не включайте в Git видео, проекты, настройки, журналы или секреты.
- Выполняйте проверки, соответствующие изменению; для GUI запускайте окно,
  для рендера проверяйте реальный короткий экспорт и декодирование.
- Не называйте проверку успешной, если она не запускалась.
- Не заявляйте качество распознавания без размеченных реальных примеров.
