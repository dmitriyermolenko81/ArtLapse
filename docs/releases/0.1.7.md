# ArtLapse 0.1.7

## Changes since 0.1.6

- Photoshop Shorts keeps the subject facing the same way when cutting to a close-up, including when the recorded canvas is mirrored.
- Close-up painting uses a fixed reference. Confirmed brushwork accumulates on its own canvas, with document-edge checks to keep Photoshop panels out of the picture.
- Long pauses can show active close-up painting while preserving the whole-model view for the return cut.
- Improved project-list persistence, music and timeline editing, and export publication with saved edit history.

## Windows

Extract the Windows x64 archive and run `ArtLapse.exe`. The archive includes FFmpeg. Compare its SHA-256 with `SHA256SUMS.txt` to verify the download.

## Изменения после 0.1.6

- В Photoshop Shorts персонаж сохраняет направление при переходе на крупный план, даже если холст в записи отзеркален.
- Мазки на крупном плане накапливаются относительно неподвижного эталона. Проверка границ холста исключает панели Photoshop.
- Во время длинных пауз можно показать работу крупным планом и затем вернуться к сохранённому общему виду.
- Улучшены сохранение списка проектов, редактирование музыки и дорожек, сохранение экспорта вместе с историей монтажа.
