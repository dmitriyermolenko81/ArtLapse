# ArtLapse 0.1.4

All updates since 0.1.3:

- Hold the left mouse button and drag to select multiple sources, versions, templates, cleanup files or episode cards. Batch actions use one confirmation; episode edits use one undo step.
- Compact video and music track icons and concise episode labels showing number and playback speed. File details remain in tooltips.
- Timeline zoom uses Ctrl + mouse wheel; redundant zoom handles were removed. Timeline boundaries retain the complete remaining episode display.
- Editor messages and errors appear in the bottom status area without a duplicate row above the tracks.
- Bottom statistics show both episodes remaining after analysis and episodes included in the final video.
- Uncertain or excessive menu-frame candidates no longer abort export with Too many menu frames. Only short isolated flashes are repaired within a limited budget; uncertain frames are retained.
- Stronger validation of saved drafts and music metadata; safer deletion of dependent versions and protection of original media.

Download the Windows ZIP, extract it completely and run ArtLapse.exe. Python, Qt and FFmpeg are included. Install into a new folder; close the app before copying your previous data folder to retain preferences. Original recordings and projects are not included in the archive.

Validation: 72 targeted tests for selection/deletion and adjacent UI behavior, Ruff, mypy, visible GUI and packaged application checks. Previous local stages also checked draft validation and real video exports. A full combined GUI test run is not claimed.
