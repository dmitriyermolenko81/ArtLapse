# ArtLapse 0.1.5

All application updates since 0.1.4.

- New optional **Keep the whole model** mode for Photoshop Shorts: assemble visible drawing updates on a persistent canvas, keeping earlier parts when the source zooms into a detail.
- Improved reference framing and stabilization across episodes, with separate handling for figures and complete drawing sheets.
- Ordinary Photoshop Shorts now use local episode framing when whole-model preservation is disabled. Fixed full-screen fallback during source pans, zooms, detection gaps and rotated-sheet views.
- Preserve intermediate painting and fill stages; prioritize confirmed work episodes while retaining a conservative reserve when needed to fill the requested duration.
- Fixed short exports caused by too few selected episodes, including the reported banana example.
- Improved canvas border, scrollbar and guide removal, plus RGB intermediate rendering and color conversion to reduce artifacts in flat tones.
- Release the active preview before deleting a version so the video file is no longer locked by playback.

## Known limits

Source canvas rotation and actual changes to the drawing remain visible. Ordinary mode does not reconstruct hidden parts; rotated sheets can retain dark workspace corners. Pixel-based matching cannot guarantee zero motion or reconstruct content never visible in the recording.

## Validation

Real original-source 60-second exports, decoding, frame-count checks, targeted framing/history/color tests and portable application smoke checks. No claim of perfect recognition on arbitrary recordings.

## Windows

Extract the complete archive and run ArtLapse.exe. Keep all bundled files together. Existing project files and original recordings are not changed by installing this release.
