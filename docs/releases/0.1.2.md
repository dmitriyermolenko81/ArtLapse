# ArtLapse 0.1.2

**[Download for Windows](https://github.com/dmitriyermolenko81/ArtLapse/releases/download/v0.1.2/ArtLapse-0.1.2-Windows-x64.zip)**

Extract the entire ZIP and run **ArtLapse.exe**. Keep `_internal` and `bin` beside
the EXE. Python, Qt and FFmpeg are included.

## Changes

- Consistent BT.709 limited-range SDR export across video, JPEG/PNG intros,
  still frames and presentation clips. Pixel values are converted before tagging.
- Prevent JPEG intros from switching the complete export to a different color format.
- Visible **v0.1.2** beside ArtLapse and in the window title; matching CLI/update version.

Re-export older affected videos from their original recordings to use the fix.
This change does not add HDR tone mapping.

## Updating

Extract to a new folder. Close ArtLapse before copying the old `data` folder to
the new application folder if you want to retain preferences. Keep projects and
original media in place. Downloads open in your browser; installation is manual.

## Verification

All 885 current test scenarios were verified across the full run and focused reruns;
a test expectation for an emulated older updater client was corrected and rerun.
Ruff, mypy, CPU/NVIDIA color tests, real exports, complete decoding, and RU/EN
source/frozen GUI checks passed. The executable is unsigned. A separate clean
Windows machine was not tested.

Dependencies are unchanged from the previously published Windows release.
The existing [optional component sources](https://github.com/dmitriyermolenko81/ArtLapse/releases/download/v0.1.0/ArtLapse-0.1.0-ThirdParty-Sources.zip)
continue to apply and are not required to run ArtLapse.
