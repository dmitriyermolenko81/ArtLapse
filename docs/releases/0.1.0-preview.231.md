# ArtLapse 0.1.0-preview.231

English | Русский

## English

This is a source preview of ArtLapse, a local Windows editor for recorded
sculpting and drawing sessions. The Python package version remains0.1.0.

- Combined trimming and episode corrections; Create video includes pending cuts.
- Keep the planned duration in all eight editing modes, including restoration of trimmed intros.
- Delete generated versions with confirmation.
- Compact episode review with automatic first selection and remembered selection.
- Inline trimming and one-row settings templates. Cancel template creation with the cross or Escape.
- Updated real English and Russian screenshots and playback GIFs.

Download **ArtLapse-0.1.0-preview.231-source.zip** and extract it. Follow
[Run from source](../../README.md#run-from-source): Python3.10+, FFmpeg/ffprobe
and the dependencies in pyproject.toml are required. There is no Windows EXE
in this release. The bundled Windows runtime is awaiting the remaining
third-party corresponding-source and notice checks described in the
[Windows distribution checklist](../launch/RELEASE_CHECKLIST.md).

Validation:51targeted tests passed; Ruff and strict mypy passed; real GUI,
playback and a short export were checked. Full pytest was not rerun.
The existing application license is retained; a public repository does not
change the license. See LICENSE and third-party notices.

## Русский

Предварительный выпуск исходников ArtLapse — локального редактора записей
скульптинга и рисования. Версия Python-пакета остаётся0.1.0.

- Подрезка и изменения эпизодов объединяются; «Создать ролик» учитывает несохранённые вырезки.
- Сохранение длительности после подрезки работает во всех восьми режимах; задетая заставка восстанавливается.
- Добавлены удаление готовых версий с подтверждением и компактное окно эпизодов с запоминанием выбора.
- Встроенная подрезка и шаблоны настроек занимают меньше места. Крестик или Escape отменяют создание шаблона.
- Обновлены реальные скриншоты и GIF на русском и английском.

Скачайте **ArtLapse-0.1.0-preview.231-source.zip**, распакуйте и выполните
[инструкцию запуска](../../README.ru.md#запуск-из-исходников). Нужны Python3.10+,
FFmpeg/ffprobe и зависимости из pyproject.toml. Готового Windows EXE в этом
релизе нет: для комплекта включённых DLL ещё не завершена проверка исходников
и уведомлений сторонних библиотек, см. [контрольный список](../launch/RELEASE_CHECKLIST.md).

Проверки:51профильный тест, Ruff, строгий mypy, настоящее окно, воспроизведение
и короткий экспорт прошли. Полный pytest повторно не запускался. Лицензия
приложения сохранена; открытие репозитория не меняет условия использования.
