# ArtLapse 0.1.1

**[Download for Windows](https://github.com/dmitriyermolenko81/ArtLapse/releases/download/v0.1.1/ArtLapse-0.1.1-Windows-x64.zip)**

Extract the entire ZIP and run **ArtLapse.exe**. Python, Qt, FFmpeg and all
required files are included. Keep `_internal` and `bin` beside the EXE.

## Changes

- Background GitHub update checks at startup and a check button in the top bar.
- Compact **Download / Later** notifications for newer stable Windows releases.
- Correct framing and scale for restored music-synced Shorts episodes,
  including saved affected edits. Manual cuts and episode timing are preserved.
- Updated instructions, screenshots and download links.

## Updating

Extract to a new folder. Close ArtLapse, then copy `data` from the old application
folder into the new one if you want to keep preferences. Keep your projects and
source recordings in place. The application opens downloads in your browser;
installation remains manual. Older releases without the update checker need
this first download manually.

## Verification

Targeted update and framing regressions, real Qt HTTP requests, RU/EN GUI and
playback checks passed. The packaged EXE was also checked against the real GitHub
API with isolated settings and a clean PATH. Archive CRC and every packaged file
were verified. The executable is unsigned; a second clean Windows machine was
not separately tested.
