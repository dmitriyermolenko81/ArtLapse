# ArtLapse 0.1.6 - fixes

- Fixed Apply after replacing music: soundtrack-only edits no longer depend on restoring a video-edit draft, modify source-selection rules, or delete the original video draft. Preparation errors are shown in the status area.
- Project lists now belong to the Windows user profile, shared across extracted versions. Existing portable settings and neighbouring ArtLapse folders are imported without moving projects, recordings or caches.
- Removed the ten-project limit and duplicate entries. Unchanged old settings do not reintroduce deleted entries. Diagnostic runs keep a separate project list.

## Upgrading

Download and extract the complete Windows archive, then run ArtLapse.exe. Updates from 0.1.5 are offered by the existing update checker.

For the first project-list migration, keep the old and new ArtLapse folders next to each other, or start the fixed build from your existing program folder. Once imported, the list is shared with subsequent fixed builds on the same Windows profile. Unrelated drives are not scanned. Project/video files stay where they are; missing or offline project paths remain listed.

## Validation

Targeted real GUI tests cover delete/add/apply/reopen/final audio export, stale video drafts and opening remembered projects from a new application folder. Portable RU/EN playback, compiled source matching, archive checksums and GitHub source checks are verified for this release.
