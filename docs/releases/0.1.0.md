# ArtLapse 0.1.0 — Windows x64

**[Скачать готовую программу / Download the complete application](https://github.com/dmitriyermolenko81/SculptCut/releases/download/v0.1.0/ArtLapse-0.1.0-Windows-x64.zip)** — 137MiB.

## Запуск

1. Скачайте **ArtLapse-0.1.0-Windows-x64.zip**.
2. Распакуйте архив целиком.
3. Откройте **ArtLapse.exe** из папки ArtLapse.

Это полная переносная программа. Python, Qt, FFmpeg/ffprobe и необходимые
библиотеки уже внутри; отдельно устанавливать их не нужно. Папки `_internal`
и `bin` оставьте рядом с EXE. Настройки создаются в `data` при первом запуске.

- Таймлапсы, ускорение и шесть режимов Shorts для скульптинга/Photoshop.
- Музыка, заставка, презентационный клип, вертикальная/квадратная компоновка.
- Совместные правки эпизодов и подрезки, учёт несохранённых вырезок при создании.
- Компактный предпросмотр эпизодов и сохранение выбора.
- Шаблоны настроек в одну строку: плюс, галочка, корзина; крестик/Escape отменяет создание.
- RU/EN, локальная обработка, сохранение исходных записей.

Проверено: экспорт во всех8режимах, полное декодирование результатов,
настоящее окно RU/EN и запуск после распаковки в каталог с кириллицей.
Минимальная фиксированная завершающая часть может увеличить слишком короткий
Photoshop-ролик; в остальных случаях используется рассчитанный монтажный план.
Сборка не подписана цифровым сертификатом; вторая чистая Windows-машина
отдельно не проверялась.

## English

Download **ArtLapse-0.1.0-Windows-x64.zip**, extract the entire archive and run
**ArtLapse.exe**. This is the complete portable application: Python, Qt,
FFmpeg/ffprobe and required libraries are included. No separate installation
is needed. Keep `_internal` and `bin` beside the EXE. Settings are created
in `data` on first launch. English and Russian interfaces are included.

Verified: actual packaged exports in all8modes, full video decoding, RU/EN GUI
playback, and launching the extracted archive from a path containing Cyrillic.
An unsigned build; a second clean Windows machine was not separately tested.
Very short Photoshop targets may be extended to preserve the readable finale.
