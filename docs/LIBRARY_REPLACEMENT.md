# Замена LGPL-библиотек

ArtLapse использует PySide6/Shiboken6 и Qt 6.8.3 как отдельные динамические
библиотеки. Qt Multimedia также поставляет собственные динамические FFmpeg DLL;
это другой комплект, чем инструменты `bin/ffmpeg.exe` и `bin/ffprobe.exe`.

Разрешены изменение и замена LGPL-компонентов, запуск приложения с совместимой
изменённой библиотекой и обратная разработка для отладки этих изменений.
Условия ArtLapse не ограничивают эти права.

Закройте программу, сделайте отдельную копию всей переносной папки и работайте
с ней. Qt DLL и плагины находятся в `_internal/PySide6`, Shiboken — в
`_internal/shiboken6`. Сохраняйте имена, структуру каталогов, архитектуру Windows
x64 и совместимость ABI с Qt/PySide6 6.8.3 и CPython 3.10. Несовместимость ABI
может препятствовать запуску; это не технический запрет замены. Для изменения
PySide6 могут потребоваться согласованные изменения Shiboken и Python bindings.

Не заменяйте системные Windows DLL. Проверяйте изменённую копию на тестовом
видео, сохраняя оригиналы. У программы нет проверки подписи заменяемых Qt DLL.
Совместимость с произвольной модифицированной библиотекой не гарантируется.

Исходники и инструкции upstream:

- Qt 6.8.3: https://download.qt.io/archive/qt/6.8/6.8.3/submodules/
- PySide/Shiboken 6.8.3: https://download.qt.io/official_releases/QtForPython/pyside6/PySide6-6.8.3-src/
- Сборка PySide: https://doc.qt.io/qtforpython-6.8/building_from_source/index.html

Это справочные адреса upstream, а не утверждение, что комплект соответствующих
исходников конкретного выпуска уже размещён. Перед публикацией бинарного
выпуска нужен проверенный комплект исходников и сведения о его сборке.
