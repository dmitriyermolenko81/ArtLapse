# Приоритет презентации — этап203

Если выбрано презентационное видео, картинка-заставка не добавляется к ролику.
Правило одинаково для презентации в начале и в конце, всех режимов, финального
экспорта и предпросмотра. Неиспользуемая картинка не увеличивает длительность,
не сдвигает музыкальную разметку и не блокирует экспорт при отсутствии файла.

В интерфейсе поле картинки отключено, подпись — «Заставка · не используется».
Путь картинки сохраняется в проекте. Отключение презентации снова включает
заставку. Для применения изменений к уже готовому ролику создайте новую версию;
старые MP4 и снимки их настроек сохраняются. Старый план, включавший одновременно
картинку и презентацию, требуется пересоздать.

Замена заставки у варианта с презентацией отключена: эта операция не может
изменить его изображение при выбранном приоритете. Для заставки отключите
презентацию и создайте новый ролик.

Регрессии: `tests/test_presentation.py` проверяет реальные CPU-экспорты и preview
с музыкой, пиксели и45кадров вместо57, позиции start/end, отсутствующую картинку,
музыкальные/ручные временные шкалы, сохранение/возврат картинки, RU/EN и GUI.
`tests/test_export_regressions.py` сохраняет проверку общей нормализации preview.

При устранении выявленного DTS-конфликта нормализация основного видео стала
соблюдать выбранный кодировщик: CPU для CPU-экспорта и preview, NVENC для
GPU-экспорта. При отказе GPU штатный внешний fallback повторяет весь экспорт
на CPU, сохраняя согласованность потоков при присоединении презентации.

Локальный кандидат: `dist/ArtLapse-203-PresentationPriority/ArtLapse.exe`.
База202 и ZIP199 сохраняются. Собственные FFmpeg/ffprobe, лицензии и исходный
комплект202 переносятся без изменения; нового ZIP приложения нет.
