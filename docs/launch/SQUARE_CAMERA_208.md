# ArtLapse208 — камера музыкальных эпизодов

Запустите `ArtLapse.exe` из `dist/ArtLapse-208-FixedMusicCamera`.
Создайте новый ролик в режиме смены видеоэпизодов под музыку и выберите
квадратную рамку. Внутри эпизода программа теперь сохраняет положение
и масштаб камеры; перецентрирование происходит на музыкальной склейке.
Правило действует для 3D и Photoshop. Готовые старые MP4 нужно создать заново.

В пользовательском AsiaTIMELAPS_music_shorts-007 обнаружены пять добавленных
панорам:6.53–7.03,9.53–10.07,36.53–37.00,38.53–39.03 и41.03–41.53с.
Причина — запасная ветка горизонтального слежения квадратной камеры.
Новый кэш не использует её старые траектории при создании ролика.

Повороты, перемещения и зум, уже записанные в ZBrush, остаются видимыми.
Размер выбранного квадрата сохраняется: объект, который шире рамки, может
обрезаться. Обычный квадратный Shorts сохраняет прежнее горизонтальное
слежение. Общая длительность включает заставку и презентацию, как в207.

Также исправлена редкая ошибка Windows при отмене обработки: программа
коротко ожидает освобождения временных файлов закрываемого процесса.
Постоянные ошибки очистки не скрываются.

Исправленная копия пользовательской минуты:
artifacts/square-camera-208/AsiaTIMELAPS-fixed-camera-208.mp4.

длительность60.000000с, видео содержит1800кадров. Все камеры неподвижны внутри
