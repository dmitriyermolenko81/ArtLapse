# Публичный выпуск ArtLapse 0.1.0

Статус бинарной раздачи: НЕ ГОТОВ К ПУБЛИЧНОЙ РАЗДАЧЕ.
Исходники готовятся отдельно; подготовка репозитория не публикует EXE/ZIP.
Уточнение состояния:2026-10-23.
Бесплатность приложения не отменяет обязательств по лицензиям зависимостей.

Подготовлено:

- Условия бесплатного личного и коммерческого использования в LICENSE.
- Добровольный Boosty без ограничения функций или требования подписки.
- Уведомления о сторонних компонентах и порядок замены LGPL-библиотек.
- RU/EN инструкции запуска, материалы анонсов и отчёты проверок приложения.
- Проверка у друга: по сообщению владельца «у друга всё работает».
  Это подтверждение работы переданной версии на другом компьютере;
  номер сборки, ОС и подробный протокол не предоставлены.
- Проверка и удаление лишнего Qt Virtual Keyboard из кандидата отдельно от
  прежнего ZIP; проверка импортов оставшихся PE-файлов и запуск кандидата.

До разрешения на публичную раздачу необходимо:

1. Завершить проверку corresponding source для Qt/PySide/Shiboken и FFmpeg DLL Qt.
   Локальный CLI уже заменён собственными ffmpeg/ffprobe8.1.2-ArtLapse-202;
   для него подготовлены исходный комплект, патчи, конфигурация и проверка
   SHA256. После очистки208 комплект находится в _internal/sources, лицензии
   в _internal/licenses/ffmpeg-own. Это не закрывает отдельную проверку Qt DLL.
   Скрипты и зафиксированные входы CLI находятся в packaging/ffmpeg.
2. Дополнить лицензионный комплект низкоуровневых библиотек: OpenSSL обеих
   версий, libffi, SQLite, Mesa/opengl32sw и сторонние компоненты Qt.
   Имеющиеся wheel LICENSE/METADATA не считаются доказательством полноты.
3. Базовый запуск у друга подтверждён пользователем. Для финального кандидата,
   если изменятся бинарники зависимостей, повторить затронутые сценарии:
   распаковка в папку с кириллицей, запуск RU/EN, импорт, preview, короткий
   экспорт, воспроизведение результата, отмена и повторный запуск.
   Не выдавать сообщение пользователя за подробный протокол всех этих сценариев.
4. Создать финальный ZIP из проверенного кандидата, проверить CRC/SHA256,
   отсутствие пользовательских данных, включить документы и исходники
   зависимостей либо проверенный способ доступа к ним рядом со скачиванием.
5. Подготовить и проверить страницу скачивания для конечных пользователей.
   Публикация, загрузка файлов и смена видимости требуют отдельного запроса
   владельца; в рамках подготовки исходников они не выполняются.

Проверка и подпись EXE — разные вещи. Цифровая подпись пока отсутствует;
возможны предупреждения Windows. Не предлагать отключение защиты системы.
Не заявлять независимую проверку безопасности или отсутствие ложных срабатываний.

Предыдущий ZIP189 остаётся прежней тестовой сборкой. Новый кандидат и отчёт
находятся в artifacts/release-194; наличие документов не делает его релизом.
