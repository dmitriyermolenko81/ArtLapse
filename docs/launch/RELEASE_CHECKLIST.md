# Windows-выпуск ArtLapse 0.1.0

## Проверенный состав — 2026-10-24

Полный Windows x64 архив: ArtLapse-0.1.0-Windows-x64.zip.
Внутри ArtLapse.exe, Python3.10.6, Qt/PySide6.8.3, FFmpeg/ffprobe
8.1.2-ArtLapse-202, необходимые DLL, лицензии и Start.txt RU/EN.
Устанавливать Python/FFmpeg отдельно не требуется; личные настройки не включены.

Проверки подготовленного бинарного комплекта:

- Сборка PyInstaller, новый продуктовый архив, CRC и SHA256 PASS.
- Чистый PATH без Python/FFmpeg: doctor и реальный экспорт во всех8режимах.
- ffprobe и полное декодирование всех8видео PASS:60кадров для5режимов,
  180кадров для3Photoshop-режимов. Для микропроверки Photoshop выбрана
  достаточная длительность6с: его читаемое завершение само занимает4с.
- Настоящее frozen окно RU/EN, воспроизведение результатов PASS.
- Полная распаковка ZIP в каталог с кириллицей, побайтная сверка всех файлов,
  запуск именно распакованной программы и создание portable data PASS.
-11профильных pytest PASS2.13с: политика состава, отмена реального процесса,
  создание/отмена/повторное открытие проекта и импорт видео.
- Код приложения тот же, что ранее проверен51профильным тестом и GitHub CI.
- Нет пользовательских проектов/видео/настроек/журналов; прежние сборки сохранены.

## Комплект зависимостей

Отдельный ArtLapse-0.1.0-ThirdParty-Sources.zip на той же странице выпуска
предоставляет29точных архивов upstream, комплект собственной сборки CLI
со всеми статическими входами/патчами/конфигурацией, источники Qt6.8.3,
PySide/Shiboken6.8.3, FFmpeg7.1 и OpenCV FFmpeg4.4.6 с его закреплёнными
зависимостями и скриптами. Полные уведомления и copyright входят в Windows ZIP.
Этот архив исходников не нужен для запуска программы.

Сверены55Qt DLL/PYD с установленным дистрибутивом6.8.3 по SHA256 и OpenCV
FFmpeg wrapper с upstream MD5. Версии и конфигурации FFmpeg прочитаны из DLL.
Копии архивов находятся под контролем распространителя. Права LGPL на замену
библиотек и отладку модификаций сохранены. См. [RUNTIME_SOURCES.md](../RUNTIME_SOURCES.md).

Исходники и исходные архивы сохранены; из публикационного комплекта CLI
удалены личные тестовые журналы, локальные пути конфигурации нормализованы.
Manifest обновлён. Побитная воспроизводимость бинарников на другой машине
не заявляется; собран полный комплект источников и сборочных инструкций.

## Практические пределы проверки

Прогон на второй физической/чистой Windows-машине не выполнялся; проверены
изоляция PATH/настроек и запуск из распакованного архива на рабочей Windows.
Цифровой сертификат подписи EXE отсутствует. Полный pytest повторно не
запускался по просьбе владельца: выполнялись необходимые профильные проверки.
Прежний блокер194 по отсутствующим source/notice материалам закрыт для
перечисленного комплекта0.1.0; исторические тестовые ZIP не переименовывались
и не объявлялись прошедшими эти новые проверки.
