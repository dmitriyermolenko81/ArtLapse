# Чистая пользовательская папка ArtLapse

Обновлена существующая папка dist/ArtLapse-208-FixedMusicCamera.
Приложение осталось версией208, его EXE и библиотеки не пересобирались.

В основной папке видны:

- ArtLapse.exe — запуск программы;
- Start.txt — первый запуск и краткие описания8режимов: русский, затем английский;
- _internal и bin — необходимые компоненты;
- data — пользовательские настройки и журналы.

Portable.txt нужен для переносного режима и остаётся в корне скрытым.
Переносить программу следует целиком, вместе со всеми служебными файлами.

Отчёты версий, длинный README и английская справка перемещены в _internal/docs.
Лицензии FFmpeg — _internal/licenses/ffmpeg-own, исходный комплект —
_internal/sources. Остальные лицензии остаются в _internal/licenses.
В _internal/docs/РАСПОЛОЖЕНИЕ_ФАЙЛОВ.txt приведены новые пути для старых отчётов.
Консольный EXE и прежняя инструкция сохранены вне пользовательской папки:
artifacts/clean-package-209/root-before.

Для следующих локальных кандидатов использовать ту же структуру и текст
packaging/Start.txt. Технические отчёты не копировать в корень.
