# Необязательный сервис обратной связи

Монтаж и экспорт не требуют этого сервиса. Здесь оставлены исходники
Cloudflare Worker и локальные тесты; личные адреса, ключи и настройки
развёртывания в репозиторий не включены.

Для своей установки скопируйте
`services/feedback/wrangler.example.jsonc` в `wrangler.jsonc` в том же
каталоге и задайте собственные идентификаторы группы и базы D1.
Примените `schema.sql` к своей базе. Ключ Telegram-бота храните только
в секретах Worker (`TELEGRAM_BOT_TOKEN`), не в клиенте и не в Git.

Публичный HTTPS-адрес приёмника можно задать переменной
`SCULPTCUT_FEEDBACK_ENDPOINT` или файлом `feedback-config.json`
по примеру `packaging/feedback-config.example.json`.
Клиентский конфиг содержит только адрес, без токенов и паролей.

Вспомогательный `connect_replies.py` предназначен для владельца своего
сервиса. Перед использованием замените шаблон `RECEIVER` своим адресом;
помощник проверяет имя бота `SculptCut_bot`. Не запускайте его для чужого
сервиса или бота. Эти настройки не нужны пользователю редактора.

Локальные тесты Worker требуют Node.js с `node:sqlite`:

```powershell
node --test services/feedback/worker.test.mjs services/feedback/replies.test.mjs
```

Синтетические ключи в тестах — фикстуры. Реальные секреты храните вне Git.
