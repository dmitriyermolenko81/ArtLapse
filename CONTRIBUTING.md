# Работа с проектом

ArtLapse — локальный редактор существующих записей. Основная платформа —
Windows x64; код приложения на Python, интерфейс на PySide6.
Условия использования и распространения определены в [LICENSE](LICENSE).

## Подготовка

Установите окружение по [README](README.md#запуск-из-исходников).
Для полного прогона нужны FFmpeg/ffprobe и доступный рабочий стол.
Документация пишется по-русски, идентификаторы и CLI — по-английски.

## Изменения

- Сохраняйте исходные видео и пользовательские проекты.
- Отделяйте анализ и планировщик от GUI, не загружайте длинное видео целиком в RAM.
- Сохраняйте время источников в целых микросекундах и целое число выходных кадров.
- Не включайте личные конфиги, ключи, видео, проекты, журналы и готовые сборки.
- В описании изменения укажите проблему, новое поведение и выполненные проверки.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m mypy src
```

Полная проверка с настоящим коротким экспортом и окном:

```powershell
.\.venv\Scripts\python.exe scripts/validate.py
```

Не называйте проверку пройденной, если она не запускалась. При изменении
рендера проверяйте число кадров через ffprobe и полное декодирование результата;
при изменении GUI открывайте настоящее окно.

GitHub Actions запускает статические проверки и два набора быстрых тестов.
Это не полный медиа/GUI-прогон. Сообщения о безопасности:
[SECURITY.md](SECURITY.md).
