ArtLapse 0.1.3 — первый запуск / First run

РУССКИЙ
1. Распакуйте всю папку и запустите ArtLapse.exe. Установка Python не нужна.
2. Создайте проект кнопкой +, добавьте видео MP4/MKV/MOV.
3. Выберите режим, длительность, музыку и нажмите «Создать ролик».
4. Включите подрезку: видео и музыка редактируются в основном окне.
Наведите мышь на нужную дорожку: Q/Й — разделить, Delete — удалить,
Ctrl+Z / Ctrl+Y — отменить / вернуть, Пробел — воспроизведение / пауза.
Тяните края фрагмента для подрезки. ПКМ на музыке добавляет плавное начало
или затухание; по умолчанию кривые выключены. Новый трек вставляйте в
свободный промежуток. В версиях «под бит» изменение музыки запрещено.
Примените правки для создания новой версии. Оригиналы не изменяются.
Готовый совместимый анализ используется повторно, статус сообщает о кэше.
Результаты — в renders проекта, прежние версии доступны в списке «Версия».
Кнопка RU / EN меняет язык. Версия видна рядом с названием программы.

ОБНОВЛЕНИЯ
Распакуйте новый выпуск в отдельную папку. Закройте приложение и перенесите
папку data из предыдущей версии, если хотите сохранить настройки.
Не перемещайте исходники и проекты. Проверка обновлений — кнопка круговой стрелки.
Не переносите только EXE: _internal и bin должны оставаться рядом.
Справка: https://github.com/dmitriyermolenko81/ArtLapse/blob/v0.1.3/README.ru.md

ENGLISH
1. Extract the entire ZIP and run ArtLapse.exe. Python, Qt and FFmpeg are included.
2. Create a project with +, add recordings and choose mode, duration and music.
3. Create a video, then enable trimming to edit video and music in the main window.
Hover a lane: Q splits, Delete removes, Ctrl+Z / Ctrl+Y undo / redo.
Space plays / pauses. Drag clip edges to trim. Right-click music to add/remove
fade-in or fade-out. Fades are off by default. Add tracks in free gaps;
existing following clips are preserved. Beat-synced versions lock music editing.
Apply edits to create a new version. Original recordings remain unchanged.
Completed compatible analysis is reused; cache reuse is shown in the status.
Results are stored in the project's renders directory. Use Version to switch results.
RU / EN switches the language. The top bar shows the application version.

UPDATES
Extract a new release into a separate folder. Close ArtLapse and copy the previous
data folder if you want to retain preferences. Keep projects and original media
in place. Use the circular-arrow button to check for updates.
Keep _internal and bin beside ArtLapse.exe. Do not move just the executable.
Guide: https://github.com/dmitriyermolenko81/ArtLapse/blob/v0.1.3/README.md
