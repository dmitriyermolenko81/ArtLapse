# Компоненты Windows-сборки ArtLapse

Собственный код приложения распространяется по LICENSE (бесплатное использование).
Права на нижеперечисленные компоненты принадлежат их правообладателям.
Условия LICENSE приложения не ограничивают права по лицензиям этих компонентов.
Пожертвование в Boosty не требуется и не меняет их лицензии.

Базовые версии зависимостей: PySide6/Essentials/Addons/Shiboken6 6.8.3,
NumPy 2.2.6, opencv-python-headless 4.12.0.88, Pydantic 2.12.5,
pydantic-core 2.41.5, annotated-types 0.8.0, typing_extensions 4.16.0,
typing-inspection 0.4.4. Python и все DLL учитываются отдельно в инвентаризации
конкретного кандидата; версии Python-пакетов не описывают все его native DLL.
Wheel METADATA и LICENSE сохраняются с исходными copyright-уведомлениями.

ArtLapse включает Python 3.10, NumPy, OpenCV, Pydantic и зависимости,
PySide6/Shiboken6 и динамические библиотеки Qt. Версии и лицензионные сведения
из установленных distributions сохранены в licenses/ рядом с ресурсами сборки.
Python LICENSE.txt и уведомления OpenCV о сторонних компонентах включены отдельно.
PyInstaller bootloader сопровождается лицензией с исключением для сборок.

PySide6/Qt доступны по нескольким лицензиям; наличие LicenseRef-Qt-Commercial
в wheel не предоставляет пользователю коммерческую лицензию. Для открытых
компонентов применимы соответствующие LGPL/GPL и исключения upstream.
Динамические Qt DLL сохранены отдельными файлами, не встроены в EXE.
Исходники соответствующих версий доступны у Qt: https://code.qt.io/
и https://download.qt.io/archive/qt/6.8/6.8.3/ .
При распространении сохраняйте весь каталог уведомлений и условия компонентов.
Инструкции по разрешённой замене библиотек: docs/LIBRARY_REPLACEMENT.md.
В новых сборках исключён неиспользуемый Qt Virtual Keyboard (GPL-only).
Это не означает, что другие модули Qt автоматически прошли полный аудит:
их встроенные зависимости и уведомления проверяются отдельно.

Переносной ZIP включает собственные ffmpeg.exe/ffprobe.exe8.1.2-ArtLapse-202
GPLv3+ в bin. Они запускаются отдельными процессами; nonfree не включён.
Их точные исходники, изменения и инструкции сборки включены в отдельный архив
ArtLapse-0.1.0-ThirdParty-Sources.zip на той же странице релиза. Он не требуется
для запуска приложения. Qt Multimedia содержит отдельные FFmpeg7.1 DLL,
а OpenCV — обёртку FFmpeg4.4.6; исходники и сборочные скрипты этих компонентов
также включены в архив зависимостей. Все динамические DLL заменяемы.

Уведомления, copyright и лицензии Qt/встроенных компонентов сохраняются
в licenses/, включая source-notices из точных исходных архивов.
Дополнены Mesa11.2.2/LLVM, OpenSSL1.1.1n/3.6.4, libffi3.3, SQLite3.37.2,
Python3.10.6 и библиотеки OpenCV/NumPy. Индекс архивов и соответствие DLL
приведены в docs/RUNTIME_SOURCES.md и runtime-sources.json.

Исходники зависимостей находятся под контролем распространителя:
https://github.com/dmitriyermolenko81/SculptCut/releases/tag/v0.1.0.
Сохранены права LGPL на замену библиотек и отладку соответствующих изменений;
лицензия приложения не отменяет прав по лицензиям сторонних компонентов.
