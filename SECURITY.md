# Сообщения о проблемах безопасности

Для обычных ошибок интерфейса используйте форму «Обратная связь» в программе.
Сообщение получает группа отзывов приложения в Telegram.

Для уязвимостей сначала отправьте через форму обратной связи краткое сообщение
«Проблема безопасности» с необязательным контактом для ответа и согласуйте
безопасную передачу подробностей. Это сообщение также увидит группа отзывов.
Не размещайте публично ключи, персональные данные, исходные видео или готовый
способ эксплуатации до обсуждения с автором. Срок ответа и программа выплат
за обнаружение уязвимостей не установлены.

Используйте актуальный выпуск из подтверждённого автором источника. Скачивание
из стороннего сообщения не подтверждает подлинность файла; сравнивайте SHA256
с контрольной суммой, опубликованной автором рядом с конкретным выпуском.
